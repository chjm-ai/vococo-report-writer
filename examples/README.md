# 公开对比示例

`site/index.html` 展示五组历史生成稿摘录：标题、开头顺序、提交状态、需求假设和证据强度。包含改善、保留与退步案例。

## 来源与脱敏

- 同一组对照来自同一个模型的旧、新规则输出，不是“未用 / 使用 Skill”的实验。
- 只选取不含人员、客户、内部项目、报价和账号的标题与段落；原始报告和未选上下文不随仓库发布。
- 引文不改词句，只将 Markdown 标题、粗体转为网页排版。第一组是人工构造会议材料的真实模型输出。
- 点评是后期人工撰写，不是模型自评，也不是对业务事实的重新核验。
- 完整输入、提示词快照和全部输出未公开，因此不能据此复现实验或计算胜率。

## 本地查看与维护

直接用浏览器打开 `site/index.html`，无需安装依赖。源文件不请求外部字体、脚本或数据，不含追踪代码；当前公网托管经过 Cloudflare，CDN 会额外附加访问统计脚本。

更新时检查：

1. 每段引文对应原始输出；删节和位置变化已说明。
2. 公开目录仅含网页产物，无私有原文、映射、截图、凭据和本机路径。
3. 320、375、768、1440 像素宽度下无横向溢出；窄屏对照上下排列。
4. 案例锚点、重点标记开关、键盘操作和来源折叠可用。
5. 脚本不可用时正文仍完整，重点标记开关隐藏。

网页样式约定见 [DESIGN.md](DESIGN.md)。临时分享只发布 `examples/site/`，不发布整个仓库。
