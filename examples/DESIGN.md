# 对比示例页

沿用原对比页的纸色背景、章节导航、旧新双栏；移除模型评分、问题词黑名单和全量内部材料。

- 方向：编辑式阅读页。正文优先，旧、新规则等宽展示，不用胜负色暗示结果。
- 桌面：五组案例纵向阅读，每组并排对照；窄屏上下排列，保留全部文字。
- 导航：页内锚点，无需 JavaScript；来源说明使用原生 details。
- 重点标记只定位点评涉及的原句，可关闭；不是自动错误检测。
- 所有颜色、字号、间距和圆角使用页面内 CSS 变量。中文系统宋体用于标题，正文使用中文无衬线字体；不请求外部字体。
- 发布目录仅 examples/site，不包含本说明、私有来源映射或运行数据。
- 源文件无追踪、外部资源、输入表单和运行时数据请求；脚本失败仍能阅读完整内容。公网 CDN 另行附加 Cloudflare 访问统计，不属于本地源码。
